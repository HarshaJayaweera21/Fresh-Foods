# Fresh Foods - Online Supermarket Website

A static website for a supermarket built with HTML, CSS, and JavaScript.

## About

Fresh Foods is a multi-page website for an online supermarket featuring product categories, shopping functionality, and customer registration. Created as a personal project to showcase frontend development skills.

## Features

- Responsive design
- Image slider on homepage
- 4 product categories: Vegetables, Dairy, Bakery, Skincare
- Order page with checkout form
- User registration page
- About Us page

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome (icons)
- Google Fonts (Poppins)

## Project Structure

```
Fresh-Foods-main/
├── index.html
├── Vegetables page.html
├── Dairy page.html
├── Bakery page.html
├── Skincare page.html
├── Order page.html
├── Registration page.html
├── About Us page.html
├── CSS/
│   └── (style sheets for each page)
└── Images/
    └── (product images)
```

## How to Run

1. Clone this repository
2. Open `index.html` in your web browser

## Note

This is a static frontend project created for educational purposes. No backend functionality is implemented.
